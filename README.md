# End-to-End RAG Application with AI Agents

## Overview
Retrieval-Augmented Generation (RAG) system built with LangChain and vector databases.

## Features
- NLP preprocessing pipeline
- Semantic search
- Embedding generation
- Vector database integration
- AI agent orchestration

## Tech Stack
- Python
- LangChain
- FAISS
- ChromaDB
- Transformers
